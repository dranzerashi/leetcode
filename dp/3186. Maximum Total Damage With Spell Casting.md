This one is crazy, I had to take the first hint. If a spell is chosen then its a given i can take all copies of the same spell.
Then maintaining the different buckets of chosen items/banned items had to be avoided by sorting the array so that i can simply skip +/- 2 elements alone instead of maintaining a banned bag of everything.
Finally had to use a running prefix max array to avoid O(n^2) and avoid the inner loop(here the loop runs at most O(3) times to skip at most 2 elements).

```python
class Solution:
    def maximumTotalDamage(self, power: List[int]) -> int:
        spells = {}
        for p in power:
            spells[p] = spells.get(p,0)+p
        #print(spells)
        spow = sorted(spells.keys())
        #spow = list(spells.keys())
        #print(spow, spells)
        dp = [spells[spow[0]]]
        mxpre = list(dp)
        for i in range(1,len(spow)):
            mx_prev = 0 
            for j in range(i-1,-1,-1):
                if spow[i]-2 <= spow[j] <= spow[i]+2:
                    continue
                mx_prev=mxpre[j]
                break
            mx = spells[spow[i]]
            mx+=mx_prev
            dp.append(mx)
            mxpre.append(max(mxpre[-1],mx))
        return max(dp)
        
```
